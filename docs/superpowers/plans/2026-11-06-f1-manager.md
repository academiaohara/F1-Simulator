# F1 Pixel Manager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convertir la base de Ciclismo Manager en un mánager de F1 offline, portable y multitemporada con estrategia y carreras pixel art.

**Architecture:** Se reutilizan framebuffer, ventana Win32, entrada y primitivas UI. El dominio se reemplaza por módulos F1 separados para datos, fin de semana, simulación, desarrollo y guardado; las pantallas consumen esas interfaces sin introducir lógica de simulación.

**Tech Stack:** C11, Win32/GDI, SQLite como fuente de generación, PowerShell/MSVC para Windows y pruebas headless C.

**Spec:** `docs/superpowers/specs/2026-11-06-f1-manager-design.md`

## Global Constraints

- Resolución lógica 640×360 y estilo pixel art.
- Un `.exe` portable sin dependencias de ejecución ni conexión a Internet.
- Partidas deterministas y versionadas.
- El jugador dirige estrategia; no conduce el coche.
- Carrera condensada, pausable y con velocidades x1–x16.

## Review Focus

- Una partida antigua debe cargarse o rechazarse con mensaje claro, nunca corromper memoria.
- Ningún compuesto puede superar sus límites reglamentarios o producir tiempos negativos.
- La IA debe decidir con información disponible, sin leer clima futuro exacto.
- Neutralizaciones y lluvia no deben bloquear la carrera ni generar paradas infinitas.
- Los límites presupuestario, ATR y de capacidad deben impedir proyectos ilegales.
